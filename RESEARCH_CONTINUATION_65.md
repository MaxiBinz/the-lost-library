# E65: the Fr 8201 continuation and a separate chant witness

**Result:** A new higher-resolution photograph makes the already published Fr 8201 text ending easier to inspect. A separately indexed Vienna manuscript contains the same two chants in succession, so that short sequence alone cannot identify one book. This does **not** disprove the published proposal that Fr 20106 and Fr 8201 belong together: the missing Fr 20106 side and any physical connection still need direct inspection.

We obtained one native-size version of the already held Fr 8201 photograph from the exact URL in the Swedish National Archives' retained public-domain-marked manifest: 1,718 × 1,156 pixels, 313,747 bytes. It is a second resolution of an existing photograph, not another fragment, side or independent witness. The new [source region](research/continuation_65/observations.json) provisionally reads *pulchrior sponso superno placuit*. This reference-exposed reading begins within the chant; the preceding Fr 20106 words are not visible here.

Grajewski's printed [2022 study](https://doi.org/10.25167/ls.4818), p. 293, already reports the Fr 20106/8201 sequence and associates those fragments. The printed page reads *sponso*. A web reader's extraction of the same PDF produces *sponsae* instead; the manuscript image supports the printed form. This is an extraction discrepancy, not evidence of a separate edition or an error in the printed publication. The 8304 different-book conclusion remains attributed to the publication and has not been fully replicated locally because the Fr 20106 image is missing.

An indexed [Cantus record for Vienna Cod. 1799 f.223v](https://cantusdatabase.org/chant/547310) identifies the same antiphon and contains the ending. The next visible Fr 8201 chant provisionally starts *Traditur ergo a patre doctoribus*. The [indexed Vienna folio navigation](https://cantusdatabase.org/chant/547315) likewise lists that chant immediately after the first one. This extension was selected after seeing the photograph and index; it is not a blind test. The direct first Cantus page and the linked Vienna image viewer did not open in the web tool, so the Vienna result is indexed metadata, not an inspection of its manuscript. The directly opened [Cantus Catherine feast table](https://cantusdatabase.org/feast/2667) lists 46 chant entries for the candidate first ID 204720. This is not a count of independent books, a prevalence estimate, or proof that all have the same text or melody. No note-by-note melodic identity was established.

An ordinary Alvin search returned seven unrelated results for `20106`, and none for the full shelfmark or `Ant 49`. That is a limited catalogue search, not evidence that the fragment has disappeared. [Sources and access outcomes](research/continuation_65/sources.json), the [acquisition protocol](research/continuation_65/protocol.json), and the [download receipt](research/continuation_65/download_receipt.json) record the precise limits. No external contact or publication occurred.

The working inventory is now 209 source-image files; the conservative recorded transfer plan is 1,676,174,588 bytes including the existing 1 GB reserve. The exact lifetime traffic is not known.
