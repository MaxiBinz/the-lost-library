**4 November 2026.** An existing frozen candidate, not a newly discovered pair. This test asks whether the reported dating discrepancy is real in the published data and whether different column counts alone exclude one book.

## Published dates

The checksum-verified [BOMPAC combined workbook](https://doi.org/10.5281/zenodo.17511106) includes all three records in reconstruction **BOMPAC-9531**. Fr 25592 / Hy 49 retains the Swedish catalogue's **12th–13th century** (`1101–1300`); Fr 29666 has **15th century** (`1401–1500`); the IV.173 row has `1401–1500` in its parsed date fields. All three rows carry the same harmonized `1401–1500` value and the dataset's own `Conflict` flag. Exact cell addresses, source hash and extraction appear in [results.json](research/continuation_107/results.json); replay using `.venv/bin/python research/continuation_107/audit.py`.

The source date intervals do not overlap. If both dates are reliable and describe the relevant medieval writing, they are substantial evidence against a single copying campaign. They are catalogue assessments, not measurements made by us: palaeographic dates can be wrong, additions or composite volumes can bridge periods, and the disputed row could have been misidentified. The group-wide 15th-century value is **harmonized, not three independent datings**. The dataset already flags the disagreement; it is not a newly found database error. E27 already noted a date conflict without this row-by-row breakdown. We have not read the authors' exact rationale for including Hy 49 or performed independent palaeographic dating.

## What the different layouts mean

The retained Fr 25592 photographs show a dense, two-column hymn layout, whereas the retained IV.173 images show one broad column with music; this difference was already reported in E27. The [Codices Fennici catalogue description of Helsinki C.ö.III.20](https://www.codicesfennici.fi/items/show/32?language=en), read in search-indexed text, describes a single Dominican-derived antiphonary with text and notation mostly in one column and selected pages in two. This is a concrete published counterexample to a **universal** rule that changing the number of columns proves separate books.

C.ö.III.20 was produced for Lutheran use in the second half of the 16th century, has multiple hands, and the record describes some notation as additions. Its two-column passages have 11–12 lines, not Fr 25592's catalogue count of 35. It does not establish how common such format changes were, whether a comparable medieval hymn section existed in IV.173, or that the proposed pair is correctly joined. No image of this comparator was inspected.

## Decision

The chronology disagreement remains a serious, explicitly flagged obstacle; the column-count difference is a clue rather than an automatic exclusion. Keep the published same-unit assignment, the national catalogue's qualified suggestion and the differing source dates separate. The most decisive further work would assess the original Fr 25592 script and notation using dated, function-matched comparators and the original IV.173/Fr 29666 evidence, while checking whether the 12th–13th-century date refers to this exact leaf. No new attribution, independent dating, independent expert review or correction is claimed. No images or files were downloaded, and no one was contacted.
